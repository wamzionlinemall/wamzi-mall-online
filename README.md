# WAMZI MALL ONLINE

Starter build for WAMZI MALL ONLINE.

## Local web build
npm install
npm run build

## Android
npm install
npm run build
npx cap add android
npx cap sync android

## GitHub Actions
Push to `main` or manually run **WAMZI MALL ONLINE - Android APK** from GitHub Actions.

## Architecture
- Vue + Vite frontend
- Express API foundation
- Capacitor 7 Android foundation
- PWA manifest
- GitHub Actions APK build

This is a clean foundation; production payments, authentication, database, delivery and seller/admin APIs must be connected before launch.
